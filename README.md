# 知识库问答 Agent

**▶ 在线查看演示页：https://lin37-c.github.io/kb-qa-agent/**

一个把个人知识库做成可问答系统的工程实践：RAG 检索 + 工具调用 + 护栏，模型自己选工具、能拒答、每次调用可回放。

## 它解决什么

知识库原来是一堆 markdown，只能靠人工翻。这个系统把它变成：能检索、能带出处回答、能拒答、能通过工具调用执行查询。

## 结构

```
src/
├─ 切片.py        文本切分（559 文件 → 10,110 块）
├─ 向量化.py      向量化入库
├─ 检索.py        相似度检索 / 二阶段重排 / 来源过滤
├─ 工具.py        14 个工具的定义与执行（统一返回 结果/证据/错误）
├─ 生成.py        带出处生成、拒答
├─ 护栏.py        拦截探针、授权闸门、审计
├─ 缓存.py        内容哈希缓存（8,842 条）
└─ 试跑_*.py      各轮实验与评测脚本
```

## 关键设计

**工具层（14 个）**：每次调用返回统一结构（结果 / 证据 / 错误），不是自由文本；缺参数、类型不对在进入业务逻辑前被拒并给出原因；工具表与护栏登记表一一对应，每次调用留痕可回放，含被拒的。

**自主选工具**：只给问题、不给工具名，模型自己挑工具并给对参数 27/27；遇到不确定的会多轮收敛。库里没有的题零调用、直接答「资料里没有」。

**护栏**：发布口令、恢复点、7 项检查链；拦截覆盖「无恢复点就改文件、用父目录跳出候选区、绝对路径直写正式区、写密钥形态、未登记工具」；拦截出口数 = 1，由代码结构保证。

## 指标（分口径报，不混成一个数）

| 指标 | 结果 |
|---|---|
| 检索严格命中 | 69.35%（含可接受块 79.03%） |
| 幻觉率 | 8.3%（上界，人工复核约 4.7%） |
| 引用可核 | 100% |
| 引用支撑 | 80.9%（下界） |

阈值用 232 条正例 / 79 条负例标定，且不跨模型沿用——换模型必须重标。

## 边界

只到本机或同网段，单 token，不做多用户隔离；换模型后上述数字不成立，需重测。

## 说明

代码按原始工程结构整理，路径与密钥已替换为占位符；运行需要自备向量库与模型 API。
